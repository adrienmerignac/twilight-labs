# ADR-0001 — Project Language

## Status

Accepted

## Context

Twilight Labs targets an international player and contributor community.

Maintaining multiple languages during the early product phase would add
complexity while the interface and domain vocabulary are still evolving.

## Decision

English is the default language for:

- user interface text;
- source code and identifiers;
- documentation;
- commits;
- issues and pull requests;
- research reports.

Original in-game labels may be preserved when required for traceability.

The maintainers may communicate privately in any language.

## Consequences

- Product copy must be written in English.
- New documentation must be written in English.
- Internationalization will be introduced later, after the product vocabulary
  becomes stable.
