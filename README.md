# ⚗️ Twilight Labs

> **Data over opinions.**

Twilight Labs is an open-source research and theorycrafting platform for **Ragnarok: Twilight Global**.

The goal is not only to identify which builds work, but to understand why they work through traceable observations, experiments, and reproducible data.

## Mission

**Collect. Understand. Analyze. Share.**

## Principles

- Data over opinions
- Raw data is sacred
- Everything is traceable
- Confidence over certainty
- Research before optimization
- Unknown means unknown
- Keep the implementation simple
- Build for contributors

Twilight Labs does not try to be right. Twilight Labs tries to be verifiable.
